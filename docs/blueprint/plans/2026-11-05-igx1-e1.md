> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `isongraph-ext 0.1.0`: a Python package that produces, verifies (V0–V5) and admits (A1–A3) IGX/1 companion bindings against the frozen Core baseline `ce9d3b78…`, with immutable baseline package data, 34 conformance vectors, and a CI that proves the pinned Core runtime is the baseline implementation.

**Architecture:** One package `isongraph_ext` with a sub-package `igx` split by responsibility: `digest` (hashing), `baselines` (immutable package data → `Baseline`/`Receipt`), `binding` (wire model, canonical-by-construction `ExtensionBinding`, V1 shape), `source` (canonicality derivation + eligibility classifier), `verify` (V0–V5), `admit` (A1–A3), `bind` (producer), `__main__` (CLI). Every rule is a frozen spec table row; every failure is an `IGXError` with `code/field/step` (verification) or an `AdmissionResult` (admission). Vectors are generated by a script from the public API plus deliberate mutations, stored byte-exact, and replayed by a parametrized runner.

**Tech Stack:** Python 3.12, `ison-py==1.2.0` (`ison_parser`), `ison-graph==1.4.1` (`ison_graph`), setuptools, pytest 8, `build`. No other runtime dependency.

## Plan rulings (deviations from spec §7 layout, not from §1–§6 content)

- **Baselines live inside the package**: `isongraph-ext/src/isongraph_ext/baselines/<core_commit>/` instead of a repo-root `baselines/`. setuptools only ships files inside the package; a root-level copy would be a second copy that could drift. Spec §6 content (MANIFEST/receipts/domains, immutability, tests) is unchanged. The `retired` flag lives in `src/isongraph_ext/baselines/REGISTRY.ison` (spec §6: "the new release's registry").
- **Blueprint copy**: `docs/blueprint/` is a verbatim copy of the blueprint folder at the time of Task 11, including `receipts/` and `plans/`; the blueprint in `isongraphext/isongraphext/docs/` remains the editing master until the user says otherwise.
- **Package README**: `isongraph-ext/README.md` is a short distribution README inside the project root (`readme = "README.md"`); the repo-root `README.md` is the long one. A `readme` path outside the project root is not a portable sdist.
- **Evidence binding**: `admit()` raises `IGXError(VERIFICATION_RESULT_MISMATCH, step="A0")` when `result.binding_digest != binding.digest`; `verify_and_admit()` is the entry point for callers who need a trustworthy decision. A hand-built `VerificationResult` is not evidence and the docs say so.
- **Historical verification**: V0 compares the installed runtime with the binding's baseline; a mismatch on a *retired* baseline yields `semantic_verification="limited"` (V4 derivations skipped, derived fields `None`), and A2 denies `producer_bound` on a limited result (`SEMANTIC_REVERIFICATION_UNAVAILABLE`). The retired fixture therefore records runtime hashes that differ from the installed Core.

## Review Focus

1. **CRLF binding file on Windows** — a binding saved by an editor that rewrites LF→CRLF must be rejected at V1 (`MALFORMED_BINDING`, field `canonical_form`), not silently accepted because a text read normalised it. Pinned in Task 4 (`test_from_ison_rejects_crlf_text`) and Task 9 (CLI reads bytes).
2. **Source supplied as `str` containing `\r\n`** — `artifact_sha256` must hash the UTF-8 of exactly that string, and a Python claim must derive `"false"` (the writer never emits CRLF). Pinned in Task 5 (`test_derive_canonical_crlf_is_false`) and Task 2 (`test_sha256_str_is_utf8_of_given_text`).
3. **Duplicate capability rows differing only in case or range** — `extension` uniqueness is exact-string; `x-igx-test` twice with different ranges is `MALFORMED_BINDING`, field `capabilities.extension`. Pinned in Task 4 (`test_duplicate_capability_rejected`).
4. **Version-range boundary semantics** — `~1.2` must admit `1.2.9` and exclude `1.3.0`; `^0.1` must admit `0.1.5` and exclude `1.0.0`; a range token like `1.2` (no operator) or `>=1.2` (two components) is malformed. Pinned in Task 6 (`test_range_boundaries`) and Task 4 (`test_bad_version_range_rejected`).
5. **ISONL profile with ISON bytes (or vice-versa)** — `serialization_profile isonl-v1` with an `.ison` document: the ISONL loader fails or re-emits differently, so a Python claim derives `"false"` and verification fails with `SOURCE_WRITER_MISMATCH`, never a stack trace. Pinned in Task 5 (`test_profile_mismatch_derives_false`).

```python
        self.detail = detail
```

```python
"""Digest framing (17 §2.1). Everything IGX/1 hashes goes through here so the framing has one home."""

from __future__ import annotations

import hashlib
from pathlib import Path


def sha256_hex(data: bytes | str) -> str:
    """sha256 of exactly these bytes; a str is UTF-8 encoded as given (no normalisation)."""
    if isinstance(data, str):
        data = data.encode("utf-8")
    return hashlib.sha256(data).hexdigest()


def sha256_file(path: Path) -> str:
    return sha256_hex(Path(path).read_bytes())


def normalize_newlines(data: bytes) -> bytes:
    """CRLF -> LF. Used only by V0 (module source identity); never for artifacts or bindings."""
    return data.replace(b"\r\n", b"\n")


def corpus_digest(root: Path) -> str:
    """Core's scripts/corpus_digest.py algorithm, reproduced so the pin can be re-derived here."""
    root = Path(root)
    h = hashlib.sha256()
    files = sorted((p for p in root.rglob("*") if p.is_file()), key=lambda p: p.relative_to(root).as_posix())
    for path in files:
        rel = path.relative_to(root).as_posix().encode("utf-8")
        h.update(rel + b"\0" + path.read_bytes() + b"\0")
    return h.hexdigest()
```

```python
#!/usr/bin/env python3
"""Build an immutable IGX/1 baseline directory from a Core checkout (17 §6).

    python scripts/make_baseline.py --core <isongraph checkout> --commit <40hex> \
        --receipts <dir with python.ison ... cpp.ison> --adopted YYYY-MM-DD --out <baselines root>

Module hashes come from `git show <commit>:path` (repository bytes, LF), never the working tree.
Domain tags are derived from the corpus manifest at <commit>; an unmapped lossy/defect cell is an error.
"""

from __future__ import annotations

import argparse
import hashlib
import re
import shutil
import subprocess
import sys
from pathlib import Path

from ison_parser import Block, Document, dumps_canonical, loads

PORTS = ("python", "ts", "js", "rust", "cs", "cpp")
MODULES = ("__init__.py", "multigraph.py", "query.py", "schema.py", "structural.py", "viz.py")
TAG_OF = {
    "ids/int64-extremes": "binary64-inexact-int",
    "values/int64-extreme-values": "binary64-inexact-int",
    "values/int-beyond-int64-inexact": "binary64-inexact-int",
    "values/int-vs-integral-float": "integral-float-collapse",
}
DEFECT_TAG_OF = {"structure/multigraph-document": "multigraph-document-accepted"}


def git_show(core: Path, commit: str, path: str) -> bytes:
    return subprocess.check_output(["git", "-C", str(core), "show", f"{commit}:{path}"])


def sha(data: bytes) -> str:
    return hashlib.sha256(data).hexdigest()


def write(path: Path, doc: Document) -> None:
    path.write_bytes(dumps_canonical(doc).encode("utf-8"))


def main(argv: list[str]) -> int:
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("--core", required=True, type=Path)
    ap.add_argument("--commit", required=True)
    ap.add_argument("--receipts", required=True, type=Path)
    ap.add_argument("--adopted", required=True)
    ap.add_argument("--out", required=True, type=Path)
    ap.add_argument("--verify", action="store_true", help="non-mutating: regenerate into a scratch dir and compare byte-for-byte with --out")
    a = ap.parse_args(argv[1:])
    if not re.fullmatch(r"[0-9a-f]{40}", a.commit):
        print("commit must be a full 40-hex id", file=sys.stderr)
        return 2
    if a.verify:
        import filecmp
        import tempfile

        with tempfile.TemporaryDirectory() as tmp:
            rc = main([argv[0], "--core", str(a.core), "--commit", a.commit, "--receipts", str(a.receipts), "--adopted", a.adopted, "--out", tmp])
            if rc:
                return rc
            want, have = Path(tmp) / a.commit, a.out / a.commit
            names = sorted(p.relative_to(want).as_posix() for p in want.rglob("*") if p.is_file())
            bad = [n for n in names if not (have / n).is_file() or (have / n).read_bytes() != (want / n).read_bytes()]
            reg_ok = any(r["core_commit"] == a.commit for b in loads((a.out / "REGISTRY.ison").read_bytes().decode("utf-8")).blocks for r in b.rows)
            print(("baseline reproduces" if not bad and reg_ok else f"MISMATCH: {bad or 'registry row missing'}"))
            return 0 if not bad and reg_ok else 1

    out = a.out / a.commit
    if out.exists():
        print(f"refusing to write into existing baseline {out} - baselines are immutable (use --verify)", file=sys.stderr)
        return 3
    (out / "receipts").mkdir(parents=True, exist_ok=True)
    receipts = {}
    for port in PORTS:
        data = (a.receipts / f"{port}.ison").read_bytes()
        (out / "receipts" / f"{port}.ison").write_bytes(data)
        receipts[port] = loads(data.decode("utf-8")).blocks[0].rows[0]
    py = receipts["python"]

    manifest = loads(git_show(a.core, a.commit, "vectors/manifest.ison").decode("utf-8"))
    rows = [r for b in manifest.blocks if (b.kind, b.name) == ("table", "vectors") for r in b.rows]
    domain_rows = []
    for port in PORTS:
        tags = set()
        for r in rows:
            cell = r[port]
            if cell == "pass:lossy":
                if r["id"] not in TAG_OF:
                    print(f"unmapped lossy vector {r['id']} for {port}", file=sys.stderr)
                    return 2
                tags.add(TAG_OF[r["id"]])
            elif cell == "defect":
                if r["id"] not in DEFECT_TAG_OF:
                    print(f"unmapped defect vector {r['id']} for {port}", file=sys.stderr)
                    return 2
                tags.add(DEFECT_TAG_OF[r["id"]])
        domain_rows += [{"port": port, "tag": t} for t in sorted(tags)]
    write(out / "domains.ison", Document(blocks=[Block(kind="table", name="domains", fields=["port", "tag"], rows=domain_rows)]))

    pyproject = git_show(a.core, a.commit, "ison-graph/pyproject.toml").decode("utf-8")
    dist_version = re.search(r'^version = "([^"]+)"', pyproject, flags=re.M).group(1)
    runtime_rows = [{"module": f"ison_graph/{m}", "sha256": sha(git_show(a.core, a.commit, f"ison-graph/src/ison_graph/{m}"))} for m in MODULES]
    file_rows = [{"path": f"receipts/{p}.ison", "sha256": sha((out / "receipts" / f"{p}.ison").read_bytes())} for p in PORTS]
    file_rows.append({"path": "domains.ison", "sha256": sha((out / "domains.ison").read_bytes())})
    meta = {
        "core_format": py["core_format"], "core_version": py["core_version"], "core_commit": a.commit,
        "core_semantic_spec": py["semantic_spec"], "core_vector_corpus_version": py["corpus_version"],
        "core_vector_corpus_commit": py["corpus_commit"], "core_vector_corpus_digest": py["corpus_digest"],
        "core_runtime_dist": "ison-graph", "core_runtime_dist_version": dist_version,
    }
    if a.commit != py["core_commit"]:
        print("receipts were not generated at --commit", file=sys.stderr)
        return 2
    write(out / "MANIFEST.ison", Document(blocks=[
        Block(kind="meta", name="baseline", fields=list(meta), rows=[meta]),
        Block(kind="table", name="files", fields=["path", "sha256"], rows=file_rows),
        Block(kind="table", name="core_runtime", fields=["module", "sha256"], rows=runtime_rows),
    ]))

    reg_path = a.out / "REGISTRY.ison"
    existing = []
    if reg_path.exists():
        existing = [r for b in loads(reg_path.read_bytes().decode("utf-8")).blocks for r in b.rows]
        if any(r["core_commit"] == a.commit for r in existing):
            print(f"registry already lists {a.commit}; rows are append-only", file=sys.stderr)
            return 3
    existing.append({"adopted": a.adopted, "core_commit": a.commit, "retired": False})
    write(reg_path, Document(blocks=[Block(kind="table", name="baselines", fields=["adopted", "core_commit", "retired"], rows=existing)]))
    print(out)
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv))
```

```python
class BaselineDataError(RuntimeError):
    """The package's baseline data does not hash to its own MANIFEST - an install problem, not a binding fault."""


@dataclass(frozen=True)
class Receipt:
    sha256: str
    port: str
    port_version: str
    posture: str
    core_commit: str
    core_format: str
    core_version: str
    corpus_commit: str
    corpus_digest: str
    corpus_version: int
    semantic_spec: str


@dataclass(frozen=True)
class Baseline:
    core_format: str
    core_version: str
    core_commit: str
    core_semantic_spec: str
    corpus_version: int
    corpus_commit: str
    corpus_digest: str
    receipts: Mapping[str, Receipt]
    domains: Mapping[str, frozenset[str]]
    core_runtime: Mapping[str, str]
    core_runtime_dist: tuple[str, str]
    retired: bool
    adopted: str


def _blocks(path: Path) -> dict[tuple[str, str], list[dict]]:
    doc = loads(path.read_bytes().decode("utf-8"))
    return {(b.kind, b.name): b.rows for b in doc.blocks}


POSTURES = ("FULL", "LOSSY_KNOWN", "KNOWN_DEFECT", "PARTIAL", "INCONCLUSIVE", "NONCONFORMANT")
COUNTERS = ("pass", "canonicalized", "lossy", "defect", "rejected_as_expected", "todo")


def _validate_receipt(baseline_name: str, port: str, r: dict) -> None:
    """A hash-valid receipt can still be internally inconsistent (17 §6). Mirror Core's corpus_receipt.py posture rules."""
    where = f"{baseline_name}/receipts/{port}.ison"
    if r.get("port") != port:
        raise BaselineDataError(f"{where}: port {r.get('port')!r} != file name")
    if r.get("posture") not in POSTURES:
        raise BaselineDataError(f"{where}: posture {r.get('posture')!r}")
    counts = {k: r.get(k) for k in COUNTERS + ("total",)}
    if any(not isinstance(v, int) or isinstance(v, bool) or v < 0 for v in counts.values()):
        raise BaselineDataError(f"{where}: counters must be non-negative integers: {counts}")
    if sum(counts[k] for k in COUNTERS) != counts["total"]:
        raise BaselineDataError(f"{where}: counters do not sum to total: {counts}")
    p, todo, lossy, defect, total = r["posture"], counts["todo"], counts["lossy"], counts["defect"], counts["total"]
    ok = {
        "FULL": todo == 0 and lossy == 0 and defect == 0,
        "LOSSY_KNOWN": todo == 0 and defect == 0 and lossy > 0,
        "KNOWN_DEFECT": todo == 0 and defect > 0,
        "PARTIAL": todo == total,
        "INCONCLUSIVE": todo > 0,
        "NONCONFORMANT": True,
    }[p]
    if not ok:
        raise BaselineDataError(f"{where}: posture {p} inconsistent with counters {counts}")


def load_baseline(directory: Path, *, retired: bool, adopted: str) -> Baseline:
    directory = Path(directory)
    blocks = _blocks(directory / "MANIFEST.ison")
    meta = blocks[("meta", "baseline")][0]
    for row in blocks[("table", "files")]:
        actual = sha256_hex((directory / row["path"]).read_bytes())
        if actual != row["sha256"]:
            raise BaselineDataError(f"{directory.name}/{row['path']}: sha256 {actual} != manifest {row['sha256']}")
    receipts: dict[str, Receipt] = {}
    for port in PORTS:
        data = (directory / "receipts" / f"{port}.ison").read_bytes()
        r = loads(data.decode("utf-8")).blocks[0].rows[0]
        _validate_receipt(directory.name, port, r)
        receipts[port] = Receipt(
            sha256=sha256_hex(data), port=r["port"], port_version=str(r["port_version"]), posture=r["posture"],
            core_commit=r["core_commit"], core_format=r["core_format"], core_version=str(r["core_version"]),
            corpus_commit=r["corpus_commit"], corpus_digest=r["corpus_digest"], corpus_version=int(r["corpus_version"]),
            semantic_spec=r["semantic_spec"],
        )
    domains: dict[str, set[str]] = {p: set() for p in PORTS}
    for row in _blocks(directory / "domains.ison").get(("table", "domains"), []):
        domains[row["port"]].add(row["tag"])
    return Baseline(
        core_format=meta["core_format"], core_version=str(meta["core_version"]), core_commit=meta["core_commit"],
        core_semantic_spec=meta["core_semantic_spec"], corpus_version=int(meta["core_vector_corpus_version"]),
        corpus_commit=meta["core_vector_corpus_commit"], corpus_digest=meta["core_vector_corpus_digest"],
        receipts=receipts, domains={p: frozenset(t) for p, t in domains.items()},
        core_runtime={r["module"]: r["sha256"] for r in blocks[("table", "core_runtime")]},
        core_runtime_dist=(meta["core_runtime_dist"], str(meta["core_runtime_dist_version"])),
        retired=retired, adopted=adopted,
    )


def load_registry(root: Path) -> dict[str, Baseline]:
    root = Path(root)
    rows = _blocks(root / "REGISTRY.ison")[("table", "baselines")]
    return {r["core_commit"]: load_baseline(root / r["core_commit"], retired=bool(r["retired"]), adopted=str(r["adopted"])) for r in rows}


def installed_core_runtime() -> tuple[tuple[str, str], dict[str, str]]:
    import ison_graph

    pkg = Path(ison_graph.__file__).parent
    hashes = {f"ison_graph/{m}": sha256_hex(normalize_newlines((pkg / m).read_bytes())) for m in CORE_MODULES}
    return ("ison-graph", importlib.metadata.version("ison-graph")), hashes


_ROOT = Path(str(importlib.resources.files("isongraph_ext") / "baselines"))
BASELINES: Mapping[str, Baseline] = load_registry(_ROOT)
DEFAULT_BASELINE: Baseline = max((b for b in BASELINES.values() if not b.retired), key=lambda b: b.adopted)
```

```python
"""Capability version ranges (17 §2): =X.Y.Z | ^X[.Y[.Z]] | ~X.Y[.Z] | >=X.Y.Z. Nothing else."""

from __future__ import annotations

import re
from dataclasses import dataclass

Version = tuple[int, int, int]
_VERSION = re.compile(r"^(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)$")
_RANGE = re.compile(r"^(=|>=|\^|~)((?:0|[1-9][0-9]*)(?:\.(?:0|[1-9][0-9]*)){0,2})$")


def parse_version(text: str) -> Version:
    m = _VERSION.match(text)
    if not m:
        raise ValueError(f"not a version X.Y.Z: {text!r}")
    return (int(m.group(1)), int(m.group(2)), int(m.group(3)))


@dataclass(frozen=True)
class Range:
    op: str
    parts: tuple[int, ...]


def parse_range(text: str) -> Range:
    m = _RANGE.match(text)
    if not m:
        raise ValueError(f"not a version range: {text!r}")
    op, parts = m.group(1), tuple(int(p) for p in m.group(2).split("."))
    if op in ("=", ">=") and len(parts) != 3:
        raise ValueError(f"{op} needs X.Y.Z: {text!r}")
    if op == "~" and len(parts) < 2:
        raise ValueError(f"~ needs X.Y[.Z]: {text!r}")
    return Range(op, parts)


def _pad(parts: tuple[int, ...]) -> Version:
    return (parts + (0, 0, 0))[:3]  # type: ignore[return-value]


def _caret_upper(parts: tuple[int, ...]) -> Version:
    """Conventional SemVer caret: bump the left-most non-zero component; if all given are zero, bump the last given."""
    p = list(parts)
    for i, value in enumerate(p):
        if value != 0:
            return _pad(tuple(p[:i] + [value + 1]))
    return _pad(tuple(p[:-1] + [p[-1] + 1]))


def range_admits(r: Range, v: Version) -> bool:
    lo = _pad(r.parts)
    if r.op == "=":
        return v == lo
    if r.op == ">=":
        return v >= lo
    if r.op == "^":
        return lo <= v < _caret_upper(r.parts)
    return lo <= v < (r.parts[0], r.parts[1] + 1, 0)  # "~"
```

```python
        blocks = [

            Block(kind="meta", name="core_baseline", fields=list(BASELINE_FIELDS), rows=[{k: row[k] for k in BASELINE_FIELDS}]),
            Block(kind="table", name="capabilities", fields=list(CAP_FIELDS),
                  rows=[{"extension": c.extension, "version_range": c.version_range, "requirement": c.requirement, "payload_sha256": c.payload_sha256} for c in self.capabilities]),

        return dumps_canonical(self.to_document())

        return sha256_hex(self.to_ison())

    def from_ison(cls, text: str | bytes) -> "ExtensionBinding":
        if isinstance(text, bytes):
            try:
                text = text.decode("utf-8")
            except UnicodeDecodeError as e:
                raise _err("document", f"not UTF-8: {e}") from None
        try:
            doc = loads(text)
        except Exception as e:  # ison_parser raises its own hierarchy; any parse failure is malformed
            raise _err("document", f"not ISON: {e}") from None
        blocks = _collect_blocks(doc)
        igx = _one_row(blocks, ("meta", "igx"), IGX_FIELDS)
        src = _one_row(blocks, ("meta", "source"), SOURCE_FIELDS)
        base = _one_row(blocks, ("meta", "core_baseline"), BASELINE_FIELDS)
        caps_block = blocks[("table", "capabilities")]
        if set(caps_block.fields) != set(CAP_FIELDS):
            raise _err("table.capabilities", f"fields {sorted(caps_block.fields)} != {sorted(CAP_FIELDS)}")
        caps = tuple(Capability(r["extension"], r["version_range"], r["requirement"], r["payload_sha256"]) for r in caps_block.rows)
        consumer = None
        if ("meta", "consumer") in blocks:
            c = _one_row(blocks, ("meta", "consumer"), CONSUMER_FIELDS)
            consumer = Consumer(c["consumer_port"], c["consumer_port_version"], c["consumer_core_posture"], c["consumer_conformance_receipt"])
        binding = cls(**{k: igx[k] for k in IGX_FIELDS}, **{k: src[k] for k in SOURCE_FIELDS}, **{k: base[k] for k in BASELINE_FIELDS},
                      capabilities=caps, consumer=consumer)
        check_shape(binding)
        if binding.to_ison() != text:
            raise _err("canonical_form", "binding bytes are not the canonical writer's output for this document")
        return binding


def _collect_blocks(doc: Document) -> dict[tuple[str, str], Block]:
    required = {("meta", "igx"), ("meta", "source"), ("meta", "core_baseline"), ("table", "capabilities")}
    allowed = required | {("meta", "consumer")}
    out: dict[tuple[str, str], Block] = {}
    for b in doc.blocks:
        key = (b.kind, b.name)
        if key not in allowed:
            raise _err(f"{b.kind}.{b.name}", "unexpected block")
        if key in out:
            raise _err(f"{b.kind}.{b.name}", "duplicate block")
        out[key] = b
    for key in sorted(required - set(out)):
        raise _err(f"{key[0]}.{key[1]}", "missing block")
    return out


def _one_row(blocks: dict, key: tuple[str, str], expected: tuple[str, ...]) -> dict[str, Any]:
    b = blocks[key]
    name = f"{key[0]}.{key[1]}"
    if len(b.rows) != 1:
        raise _err(name, f"expected exactly one row, got {len(b.rows)}")
    row = b.rows[0]
    for f in expected:
        if f not in row:
            raise _err(f"{name}.{f}", "missing field")
    for f in row:
        if f not in expected:
            raise _err(f"{name}.{f}", "unexpected field")
    return row


def _is_str(v: Any) -> bool:
    return isinstance(v, str) and not isinstance(v, bool)
```

```python
"""Runtime-derived facts about the source artifact (17 §4 V4, §4.1). Never trust the caller for these."""

from __future__ import annotations

from ison_graph import MULTIGRAPH_FORMAT, ISONGraph
from ison_graph.multigraph import MultiGraph
from ison_parser import loads, loads_isonl

INT64_MIN = -(2**63)
INT64_MAX = 2**63 - 1


def as_bytes(source: str | bytes) -> bytes:
    return source.encode("utf-8") if isinstance(source, str) else source


def _parse(text: str, profile: str):
    return loads_isonl(text) if profile == "isonl-v1" else loads(text)


def _is_multigraph_document(doc) -> bool:
    for b in doc.blocks:
        if (b.kind, b.name) == ("meta", "graph"):
            for row in b.rows:
                if row.get("format") == MULTIGRAPH_FORMAT:
                    return True
    return False


def _load(source: bytes, profile: str):
    """Load with the pinned Python Core using the profile's loader. Raises on anything the Core rejects."""
    text = source.decode("utf-8")  # strict: a non-UTF-8 artifact is not the writer's output
    doc = _parse(text, profile)
    cls = MultiGraph if _is_multigraph_document(doc) else ISONGraph
    graph = cls.from_isonl(text) if profile == "isonl-v1" else cls.from_ison(text)
    return graph, doc


def _emit(graph, profile: str) -> bytes:
    return (graph.to_isonl() if profile == "isonl-v1" else graph.to_ison()).encode("utf-8")


def derive_canonical(source: bytes, profile: str, producer_port: str) -> str:
    if producer_port != "python":
        return "unverified"
    try:
        graph, _ = _load(source, profile)
        emitted = _emit(graph, profile)
    except Exception:
        return "false"
    return "true" if source in (emitted, emitted + b"\n") else "false"


def _int_out_of_range(value) -> bool:
    return isinstance(value, int) and not isinstance(value, bool) and not (INT64_MIN <= value <= INT64_MAX)


def classify_eligibility(source: bytes, profile: str) -> tuple[str, str | None]:
    try:
        graph, doc = _load(source, profile)
    except Exception:
        return ("unclassified", None)
    if _is_multigraph_document(doc):
        return ("ineligible", "MULTIGRAPH_DOCUMENT")
    for node in graph.nodes():
        if _int_out_of_range(node.id) or any(_int_out_of_range(v) for v in node.properties.values()):
            return ("ineligible", "INTEGER_OUT_OF_INT64")
    for edge in graph.edges():
        if any(_int_out_of_range(v) for v in edge.properties.values()):
            return ("ineligible", "INTEGER_OUT_OF_INT64")
    return ("eligible", None)
```

```python
"""Historical verification, V0-V5 (17 §4). Raises IGXError at the first failing step; returns only on full success."""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass

from .baselines import BASELINES, Baseline, Receipt, installed_core_runtime
from .binding import Capability, ExtensionBinding, check_shape
from .digest import sha256_hex
from .errors import IGXError
from .source import as_bytes, classify_eligibility, derive_canonical
from .versions import parse_range, parse_version, range_admits

CapabilityRegistry = Mapping[str, str]
EMPTY_REGISTRY: CapabilityRegistry = {}


@dataclass(frozen=True)
class VerificationResult:
    binding_digest: str
    semantic_verification: str                 # "full" | "limited" (17 §4 V0)
    source_canonical: str | None               # derived in full mode; None in limited mode
    source_semantic_eligibility: str | None
    source_semantic_reason: str | None
    unrecognized_optional: tuple[Capability, ...]
    steps_passed: tuple[str, ...]


def resolve_baseline(binding: ExtensionBinding, baselines: Mapping[str, Baseline]) -> Baseline:
    try:
        return baselines[binding.core_commit]
    except KeyError:
        raise IGXError("CORE_BASELINE_UNSUPPORTED", "meta.core_baseline.core_commit", f"unknown Core baseline {binding.core_commit}", "V2") from None


def _runtime_mismatch(baseline: Baseline) -> tuple[str, str] | None:
    """(field, detail) of the first difference between the installed Core and the baseline's recorded runtime, or None."""
    dist, hashes = installed_core_runtime()
    if dist != baseline.core_runtime_dist:
        return ("ison-graph", f"installed {dist} != baseline {baseline.core_runtime_dist}")
    for module, expected in baseline.core_runtime.items():
        if hashes.get(module) != expected:
            return (module, f"installed {hashes.get(module)} != baseline {expected}")
    return None


def _v0(baseline: Baseline) -> str:
    """Returns the semantic verification mode. A retired baseline whose runtime is gone is 'limited', never an error."""
    mismatch = _runtime_mismatch(baseline)
    if mismatch is None:
        return "full"
    if baseline.retired:
        return "limited"
    raise IGXError("CORE_RUNTIME_MISMATCH", mismatch[0], mismatch[1], "V0")


def _v2(b: ExtensionBinding, base: Baseline) -> None:
    for field, mine, theirs in (("core_format", b.core_format, base.core_format), ("core_version", b.core_version, base.core_version),
                                ("core_semantic_spec", b.core_semantic_spec, base.core_semantic_spec)):
        if mine != theirs:
            raise IGXError("CORE_BASELINE_UNSUPPORTED", f"meta.core_baseline.{field}", f"{mine!r} != baseline {theirs!r}", "V2")
    for field, mine, theirs in (("core_vector_corpus_version", b.core_vector_corpus_version, base.corpus_version),
                                ("core_vector_corpus_commit", b.core_vector_corpus_commit, base.corpus_commit),
                                ("core_vector_corpus_digest", b.core_vector_corpus_digest, base.corpus_digest)):
        if mine != theirs:
            raise IGXError("CORPUS_DIGEST_MISMATCH", f"meta.core_baseline.{field}", f"{mine!r} != baseline {theirs!r}", "V2")


def _receipt_check(base: Baseline, port: str, version: str, posture: str, digest: str, prefix: str, names: tuple[str, str, str, str]) -> Receipt:
    f_port, f_version, f_posture, f_digest = names
    receipt = base.receipts.get(port)
    if receipt is None:
        raise IGXError("RECEIPT_REFERENCE_INVALID", f"{prefix}.{f_port}", f"baseline has no receipt for {port}", "V3")
    if digest != receipt.sha256:
        raise IGXError("RECEIPT_REFERENCE_INVALID", f"{prefix}.{f_digest}", f"{digest} is not the {port} receipt {receipt.sha256}", "V3")
    if version != receipt.port_version:
        raise IGXError("RECEIPT_REFERENCE_INVALID", f"{prefix}.{f_version}", f"{version!r} != receipt {receipt.port_version!r}", "V3")
    if posture != receipt.posture:
        raise IGXError("RECEIPT_REFERENCE_INVALID", f"{prefix}.{f_posture}", f"{posture} != receipt {receipt.posture}", "V3")
    for name, mine, theirs in (("core_commit", receipt.core_commit, base.core_commit), ("core_format", receipt.core_format, base.core_format),
                               ("core_version", receipt.core_version, base.core_version), ("corpus_version", receipt.corpus_version, base.corpus_version),
                               ("corpus_commit", receipt.corpus_commit, base.corpus_commit), ("corpus_digest", receipt.corpus_digest, base.corpus_digest),
                               ("semantic_spec", receipt.semantic_spec, base.core_semantic_spec)):
        if mine != theirs:
            raise IGXError("RECEIPT_REFERENCE_INVALID", f"receipt.{name}", f"{port} receipt says {mine!r}, baseline {theirs!r}", "V3")
    return receipt


def _v3(b: ExtensionBinding, base: Baseline) -> None:
    _receipt_check(base, b.producer_port, b.producer_port_version, b.producer_core_posture, b.core_conformance_receipt, "meta.core_baseline",
                   ("producer_port", "producer_port_version", "producer_core_posture", "core_conformance_receipt"))
    if b.consumer is not None:
        c = b.consumer
        _receipt_check(base, c.port, c.port_version, c.posture, c.receipt_sha256, "meta.consumer",
                       ("consumer_port", "consumer_port_version", "consumer_core_posture", "consumer_conformance_receipt"))


def _v4(b: ExtensionBinding, source: bytes, mode: str) -> tuple[str | None, str | None, str | None]:
    actual = sha256_hex(source)
    if actual != b.artifact_sha256:
        raise IGXError("SOURCE_BINDING_MISMATCH", "meta.source.artifact_sha256", f"supplied bytes hash to {actual}", "V4")
    if mode == "limited":
        return None, None, None            # re-derivation needs the pinned runtime, which this install is not (17 §4 V0)
    canonical = derive_canonical(source, b.serialization_profile, b.producer_port)
    if canonical != b.source_canonical:
        raise IGXError("SOURCE_WRITER_MISMATCH", "meta.source.source_canonical", f"derived {canonical!r}, stored {b.source_canonical!r}", "V4")
    eligibility, reason = classify_eligibility(source, b.serialization_profile)
    if (eligibility, reason) != (b.source_semantic_eligibility, b.source_semantic_reason):
        raise IGXError("SOURCE_ELIGIBILITY_MISMATCH", "meta.source.source_semantic_eligibility",
                       f"derived ({eligibility}, {reason}), stored ({b.source_semantic_eligibility}, {b.source_semantic_reason})", "V4")
    return canonical, eligibility, reason


def _v5(b: ExtensionBinding, registry: CapabilityRegistry) -> tuple[Capability, ...]:
    unrecognized: list[Capability] = []
    for cap in b.capabilities:
        registered = registry.get(cap.extension)
        admitted = registered is not None and range_admits(parse_range(cap.version_range), parse_version(registered))
        if cap.requirement == "REQUIRED" and not admitted:
            why = "not in registry" if registered is None else f"range {cap.version_range} excludes registered {registered}"
            raise IGXError("UNSUPPORTED_CAPABILITY", f"table.capabilities.{cap.extension}", why, "V5")
        if cap.requirement == "OPTIONAL" and not admitted:
            unrecognized.append(cap)
    return tuple(unrecognized)


def verify(binding: ExtensionBinding, source: str | bytes, *, baselines: Mapping[str, Baseline] = BASELINES,
           registry: CapabilityRegistry = EMPTY_REGISTRY) -> VerificationResult:
    base = resolve_baseline(binding, baselines)      # unknown commit -> V2 (no baseline to run V0 against)
    mode = _v0(base)
    check_shape(binding)                              # V1 on programmatic bindings; from_ison already ran it on parsed ones
    _v2(binding, base)
    _v3(binding, base)
    canonical, eligibility, reason = _v4(binding, as_bytes(source), mode)
    unrecognized = _v5(binding, registry)
    return VerificationResult(binding_digest=binding.digest, semantic_verification=mode, source_canonical=canonical,
                              source_semantic_eligibility=eligibility, source_semantic_reason=reason,
                              unrecognized_optional=unrecognized, steps_passed=("V0", "V1", "V2", "V3", "V4", "V5"))
```

```python
"""Operational admission, A1-A3 (17 §4.2). Policy denials are results, never exceptions."""

from __future__ import annotations

from collections.abc import Mapping
from dataclasses import dataclass

from .baselines import BASELINES, Baseline
from .binding import ExtensionBinding
from .verify import VerificationResult, resolve_baseline


@dataclass(frozen=True)
class AdmissionPolicy:
    accept_lossy_domains: frozenset[str] = frozenset()   # RESERVED in E1 (17 §3): reported, never applied
    allow_retired_baselines: bool = False


DEFAULT_POLICY = AdmissionPolicy()


@dataclass(frozen=True)
class AdmissionResult:
    admitted: bool
    code: str | None
    step: str | None
    receipt_posture: str
    reasons: tuple[str, ...]


def _deny(code: str, step: str, reasons: list[str]) -> AdmissionResult:
    return AdmissionResult(False, code, step, "INADMISSIBLE", tuple(reasons))


def admit(binding: ExtensionBinding, result: VerificationResult, *, policy: AdmissionPolicy = DEFAULT_POLICY,
          baselines: Mapping[str, Baseline] = BASELINES) -> AdmissionResult:
    """Decide on a binding given the VerificationResult verify() produced FOR THIS BINDING.

    A result for another binding is not a policy question: it raises. A hand-built VerificationResult is not
    evidence; callers who need a trustworthy decision use verify_and_admit().
    """
    if result.binding_digest != binding.digest:
        raise IGXError("VERIFICATION_RESULT_MISMATCH", "result.binding_digest",
                       f"result is for {result.binding_digest}, binding is {binding.digest}", "A0")
    base = resolve_baseline(binding, baselines)
    reasons: list[str] = []
    if policy.accept_lossy_domains:
        reasons.append("POLICY_FIELD_RESERVED")

    # A1 currency
    if base.retired and not policy.allow_retired_baselines:
        return _deny("STALE_BINDING", "A1", reasons + ["BASELINE_RETIRED"])

    # A2 claim
    claim, posture = binding.identity_claim, binding.producer_core_posture
    if claim == "cross_port":
        denial = ["SEMANTIC2_NOT_FROZEN"] + (["CONSUMER_REQUIRED"] if binding.consumer is None else [])
        return _deny("IDENTITY_CLAIM_INADMISSIBLE", "A2", reasons + denial)
    if claim == "producer_bound":
        denial: list[str] = []
        if result.semantic_verification != "full":
            denial.append("SEMANTIC_REVERIFICATION_UNAVAILABLE")   # stored eligibility was not re-derived: a claim, not evidence
        if posture == "LOSSY_KNOWN":
            denial.append("LOSSY_PRODUCER_BOUND_RESERVED")
        elif posture == "KNOWN_DEFECT":
            denial.append("CORE_BLOCKING_DIVERGENCE")
        elif posture != "FULL":
            denial.append(f"PRODUCER_POSTURE_{posture}")
        if result.source_semantic_eligibility == "ineligible":
            denial.append(f"SOURCE_NOT_ELIGIBLE:{result.source_semantic_reason}")
        elif result.source_semantic_eligibility == "unclassified":
            denial.append("SOURCE_UNCLASSIFIED")
        if denial:
            return _deny("IDENTITY_CLAIM_INADMISSIBLE", "A2", reasons + denial)

    # A3 consumer (reporting only)
    receipt_posture = "OK"
    if binding.consumer is not None:
        cp = binding.consumer.posture
        if cp in ("KNOWN_DEFECT", "PARTIAL", "INCONCLUSIVE", "NONCONFORMANT"):
            receipt_posture = "CORE_BLOCKING_DIVERGENCE"
            reasons.append(f"CONSUMER_POSTURE_{cp}")
        elif cp == "LOSSY_KNOWN":
            receipt_posture = "CORE_LOSSY"
            reasons.append("CONSUMER_POSTURE_LOSSY_KNOWN")
    return AdmissionResult(True, None, None, receipt_posture, tuple(reasons))


def verify_and_admit(binding: ExtensionBinding, source: str | bytes, *, baselines: Mapping[str, Baseline] = BASELINES,
                     registry: CapabilityRegistry = EMPTY_REGISTRY, policy: AdmissionPolicy = DEFAULT_POLICY
                     ) -> tuple[VerificationResult, AdmissionResult]:
    """The trustworthy entry point: the result handed to admit() is the one verify() just produced for this binding and these bytes."""
    result = verify(binding, source, baselines=baselines, registry=registry)
    return result, admit(binding, result, policy=policy, baselines=baselines)
```

```python
"""Producer path (17 §3 bind): derive, build, verify, admit - never return what you would not admit."""

from __future__ import annotations

from collections.abc import Sequence

from .admit import DEFAULT_POLICY, AdmissionPolicy, admit
from .baselines import BASELINES, DEFAULT_BASELINE, Baseline
from .binding import IDENTITY_CLAIMS, PORTS, PROFILES, WRITER_OF_PORT, Capability, Consumer, ExtensionBinding
from .digest import sha256_hex
from .errors import IGXError
from .source import as_bytes, classify_eligibility, derive_canonical
from .verify import EMPTY_REGISTRY, CapabilityRegistry, _runtime_mismatch, verify


def bind(source: str | bytes, *, serialization_profile: str, producer_port: str, identity_claim: str,
         capabilities: Sequence[Capability] = (), consumer: Consumer | None = None, baseline: Baseline = DEFAULT_BASELINE,
         registry: CapabilityRegistry = EMPTY_REGISTRY, policy: AdmissionPolicy = DEFAULT_POLICY) -> ExtensionBinding:
    data = as_bytes(source)
    # Argument shape is V1 territory - the same enum rule check_shape() applies to a parsed binding (17 §4 V1).
    if producer_port not in PORTS:
        raise IGXError("MALFORMED_BINDING", "meta.core_baseline.producer_port", f"not one of {PORTS}", "V1")
    if identity_claim not in IDENTITY_CLAIMS:
        raise IGXError("MALFORMED_BINDING", "meta.igx.identity_claim", f"not one of {IDENTITY_CLAIMS}", "V1")
    if serialization_profile not in PROFILES:
        raise IGXError("MALFORMED_BINDING", "meta.source.serialization_profile", f"not one of {PROFILES}", "V1")
    receipt = baseline.receipts.get(producer_port)
    if receipt is None:
        raise IGXError("RECEIPT_REFERENCE_INVALID", "meta.core_baseline.producer_port", f"baseline {baseline.core_commit} has no receipt for {producer_port!r}", "V3")
    mismatch = _runtime_mismatch(baseline)
    if mismatch is not None:
        # Producing needs the pinned implementation to derive canonicality/eligibility; only verifying tolerates its absence.
        raise IGXError("CORE_RUNTIME_MISMATCH", mismatch[0], mismatch[1], "V0")
    canonical = derive_canonical(data, serialization_profile, producer_port)
    if canonical == "false":
        raise IGXError("SOURCE_WRITER_MISMATCH", "meta.source.source_canonical", "the Python writer does not reproduce these bytes under this profile", "V4")
    eligibility, reason = classify_eligibility(data, serialization_profile)
    binding = ExtensionBinding(
        identity_claim=identity_claim, artifact_sha256=sha256_hex(data), serialization_profile=serialization_profile,

        core_vector_corpus_commit=baseline.corpus_commit, core_vector_corpus_digest=baseline.corpus_digest,
        producer_port=producer_port, producer_port_version=receipt.port_version, producer_core_posture=receipt.posture,
        core_conformance_receipt=receipt.sha256, capabilities=tuple(capabilities), consumer=consumer,
    )
    baselines = {**BASELINES, baseline.core_commit: baseline}
    result = verify(binding, data, baselines=baselines, registry=registry)
    decision = admit(binding, result, policy=policy, baselines=baselines)
    if not decision.admitted:
        field = "meta.core_baseline.core_commit" if decision.code == "STALE_BINDING" else "meta.igx.identity_claim"
        raise IGXError(decision.code or "IDENTITY_CLAIM_INADMISSIBLE", field, "; ".join(decision.reasons), decision.step or "A2")
    return binding
```

```python
"""CLI (17 §3): verify -> 0/1, admit -> 0/2 (1 on invalid). Output is ISON so receipts can quote it verbatim."""

from __future__ import annotations

import argparse
import sys
from pathlib import Path

from ison_parser import Block, Document, dumps_canonical

from .admit import AdmissionPolicy, admit
from .binding import ExtensionBinding
from .errors import IGXError
from .verify import verify


def _emit(name: str, row: dict) -> None:
    sys.stdout.write(dumps_canonical(Document(blocks=[Block("meta", name, list(row), [row])])) + "\n")


def _error(e: IGXError) -> int:
    _emit("error", {"code": e.code, "field": e.field, "detail": e.detail, "step": e.step})
    return 1


def _joined(items) -> str | None:
    return ",".join(items) if items else None


EX_USAGE = 64   # BSD sysexits: never collides with 2 (admission denied) or 1 (invalid binding)


class _Parser(argparse.ArgumentParser):
    def error(self, message: str) -> None:  # type: ignore[override]
        self.print_usage(sys.stderr)
        sys.stderr.write(f"error: {message}\n")
        raise SystemExit(EX_USAGE)


def main(argv: list[str]) -> int:
    ap = _Parser(prog="python -m isongraph_ext.igx")
    sub = ap.add_subparsers(dest="cmd", required=True)
    for name in ("verify", "admit"):
        p = sub.add_parser(name)
        p.add_argument("graph", type=Path)
        p.add_argument("binding", type=Path)
        if name == "admit":
            p.add_argument("--allow-retired", action="store_true")
    a = ap.parse_args(argv)
    try:
        source = a.graph.read_bytes()
        binding_bytes = a.binding.read_bytes()
    except OSError as e:
        sys.stderr.write(f"error: {e}\n")
        return EX_USAGE
    try:
        binding = ExtensionBinding.from_ison(binding_bytes)
        result = verify(binding, source)
    except IGXError as e:
        return _error(e)
    if a.cmd == "verify":
        _emit("verification", {
            "binding_digest": result.binding_digest, "source_canonical": result.source_canonical,
            "source_semantic_eligibility": result.source_semantic_eligibility, "source_semantic_reason": result.source_semantic_reason,
            "steps_passed": _joined(result.steps_passed),
            "unrecognized_optional": _joined(c.extension for c in result.unrecognized_optional)})
        return 0
    decision = admit(binding, result, policy=AdmissionPolicy(allow_retired_baselines=a.allow_retired))
    _emit("admission", {"admitted": decision.admitted, "code": decision.code, "step": decision.step,
                        "receipt_posture": decision.receipt_posture, "reasons": _joined(decision.reasons)})
    return 0 if decision.admitted else 2


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
```

```python
def check(graph_rel: str, text: str, registry: str, expect: str, step: str | None) -> None:
    source, tokens = graph(graph_rel), expect.split("+")
    rejects = [t for t in tokens if t.startswith("reject:")]
    try:
        binding = ExtensionBinding.from_ison(text)
        result = verify(binding, source, baselines=B, registry=REG[registry])
    except IGXError as e:
        assert rejects and (e.code, e.step) == (rejects[0][7:], step), (expect, e)
        return
    assert not rejects, expect
    decision = admit(binding, result, baselines=B)
    for t in tokens:
        if t == "admit_ok":
            assert decision.admitted, decision
        elif t.startswith("admit:"):
            assert (decision.code, decision.step) == (t[6:], step), decision
        elif t.startswith("admit_posture:"):
            assert decision.receipt_posture == t[14:], decision
        elif t.startswith("retired:"):
            d = admit(binding, result, policy=AdmissionPolicy(allow_retired_baselines=True), baselines=B)
            assert (d.code, d.step) == (t[8:], step), d
        elif t == "retired_ok":
            assert admit(binding, result, policy=AdmissionPolicy(allow_retired_baselines=True), baselines=B).admitted


def main() -> int:
    (VEC / "bindings").mkdir(parents=True, exist_ok=True)
    rows = []
    for vid, graph_rel, text, registry, expect, step, detail in VECTORS:
        check(graph_rel, text, registry, expect, step)
        fname = vid.replace("/", "--") + ".igx.ison"
        (VEC / "bindings" / fname).write_bytes(text.encode("utf-8"))
        rows.append({"id": vid, "graph": graph_rel, "binding": fname, "registry": registry, "expect": expect, "step": step, "detail": detail})
    doc = Document(blocks=[
        Block("meta", "corpus", ["version", "binding_spec"], [{"version": 1, "binding_spec": "IGX/1"}]),
        Block("table", "vectors", ["id", "graph", "binding", "registry", "expect", "step", "detail"], rows),
    ])
    (VEC / "manifest.ison").write_bytes((dumps_canonical(doc) + "\n").encode("utf-8"))
    print(f"{len(rows)} vectors written")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```
