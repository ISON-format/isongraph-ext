# ISONGraphExt - protocol documents

The documents in this directory are the normative texts the code and conformance vectors follow. Code follows them, never the reverse.

| Document | Subject |
|---|---|
| `16-CORE-BASELINE-AND-COMPATIBILITY-CONTRACT.md` | The contract between Ext and an ISONGraph Core baseline (Core Conformance Receipts, admission rules, failure codes) |
| `17-IGX1-DESIGN.md` | IGX/1: extension binding, capability registry, identity claims, verification and admission |
| `18-IGPV1-DESIGN.md` | IGPV/1: provenance - source attribution, locators and derivation lineage |
| `19-IGDM1-DESIGN.md` | IGDM/1: Datamatics - renderer-neutral presentation intent |
| `13-SEMANTIC-2.md` | Draft graph-identity contract (Semantic/2); not yet frozen |
| `15-CORE-CONFORMANCE-CORPUS.md` | Specification of the Core conformance corpus the receipts refer to |
| `02-CORE-COMPATIBILITY-LAWS.md`, `11-ADRS.md` | Compatibility laws and architecture decisions |
| `receipts/` | The six Core Conformance Receipts embedded in the package (read by the baseline generator and CI) |

Other numbered documents that the specifications cite (for example `01`, `04`, `05`, `12`, `14`) are internal planning notes and are not part of this distribution; each specification is self-contained for implementation purposes.
